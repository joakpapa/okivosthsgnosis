# Ο Κύβος της Γνώσης — Site ΚΔΑΠ & Βρεφονηπιακού Σταθμού (HTML/CSS/JS)

Κοπανός, Ημαθία · Υπεύθυνη: Μουρατίδου Μαρία

## Δομή αρχείων
```
index.html          Αρχική
about.html           Ποιοι Είμαστε (+ υπεύθυνη, ΕΣΠΑ, FAQ)
activities.html      Δραστηριότητες (+ gallery + έλεγχος ηλικίας)
news.html            Ανακοινώσεις / Νέα
booking.html         Ραντεβού βιντεοκλήσης
contact.html         Επικοινωνία
css/style.css        Όλο το στυλ
js/include.js        Φορτώνει header/footer σε κάθε σελίδα (partials)
js/main.js           Μενού, scroll-reveal, gallery, FAQ, back-to-top, φόρμα επικοινωνίας
js/booking.js        Το σύστημα ραντεβού + δημιουργία link βιντεοκλήσης
js/age-checker.js    Έλεγχος ηλικίας παιδιού (για το τμήμα ΚΔΑΠ)
js/content.js        Φορτώνει τα content/*.json (τα επεξεργάζεται το CMS)
content/*.json       Τίτλοι, φωτογραφίες, δραστηριότητες, gallery, FAQ, ανακοινώσεις — όλα επεξεργάσιμα από το CMS
admin/               Πίνακας διαχείρισης (Decap CMS) — βλ. παρακάτω
partials/            Κοινό header.html & footer.html (στοιχεία επικοινωνίας εδώ)
```

## ⚠️ Πριν το ανεβάσεις — έλεγξε/συμπλήρωσε αυτά

Τα βασικά στοιχεία (τηλέφωνο, email, διεύθυνση, Instagram) είναι ήδη
μπασμένα. Έχουν μείνει ωστόσο **placeholder** στοιχεία που πρέπει να
αντικαταστήσεις με πραγματικά, πριν πάει live το site:

- **Ωράριο λειτουργίας** (`partials/footer.html`, `contact.html`) — βάλε
  το πραγματικό.
- **Στατιστικά στην αρχική** (`content/home.json`: statYears, statKids,
  statActivities) — αυτοί οι αριθμοί είναι ενδεικτικοί, άλλαξέ τους από
  τον πίνακα διαχείρισης.
- **Testimonials** (`index.html`, ενότητα "Τι λένε οι γονείς") — είναι
  ενδεικτικά κείμενα, αντικατέστησέ τα με πραγματικά σχόλια γονέων (ή
  αφαίρεσέ τα μέχρι να έχεις πραγματικά).
- **Φωτογραφίες** (`activities.html`, `about.html`) — αυτή τη στιγμή
  είναι τυχαίες ενδεικτικές φωτογραφίες (picsum.photos)· ανέβασε
  πραγματικές από το Instagram/Facebook σας μέσω του CMS.
- **Εύρος ηλικιών βρεφικού τμήματος** — δεν έχω σίγουρο στοιχείο, βεβαιώσου
  ότι το κείμενο στο `about.html`/`index.html` αντιστοιχεί σε αυτό που
  ισχύει πραγματικά στο βρεφικό σας τμήμα.

## Ρύθμιση φορμών (δωρεάν, ~2 λεπτά)

Πήγαινε στο https://web3forms.com, βάλε το email σου, πάρε ένα δωρεάν
"Access Key" και αντικατέστησε το `ΒΑΛΕ_ΤΟ_ACCESS_KEY_ΣΟΥ` στα αρχεία
`js/main.js` και `js/booking.js`. Χωρίς αυτό, οι φόρμες δεν στέλνουν email.

Η βιντεοκλήση γίνεται μέσω **Jitsi Meet** (meet.jit.si) — 100% δωρεάν,
χωρίς λογαριασμό. Κάθε ραντεβού παίρνει αυτόματα ένα μοναδικό link.

## Πίνακας Διαχείρισης (CMS) — αλλαγή κειμένων χωρίς κώδικα

Το site έχει ήδη ενσωματωμένο ένα δωρεάν CMS (Decap CMS) στον φάκελο
`admin/`. Για να δουλέψει το login χρειάζεται **Netlify** (το πιο απλό,
δωρεάν auth). Βήματα:

1. Ανέβασε το site σε GitHub repository.
2. Deploy στο https://netlify.com (σύνδεσε το repository — δωρεάν).
3. Στο Netlify: **Site settings → Identity → Enable Identity**.
4. **Identity → Registration**: όρισε "Invite only" (ασφαλέστερο).
5. **Identity → Services → Git Gateway → Enable Git Gateway**.
6. **Identity → Invite users** → βάλε το email σου (ή της κ. Μουρατίδου).
7. Θα λάβεις email πρόσκλησης — μπες, όρισε κωδικό.
8. Πήγαινε στο `το-site-σου.netlify.app/admin` — συνδέσου και επεξεργάσου:
   - **Αρχική Σελίδα**: τίτλους, στατιστικά, κύρια φωτογραφία (hero)
   - **Ποιοι Είμαστε**: τη φωτογραφία της σελίδας
   - **Δραστηριότητες**: προσθήκη/αφαίρεση δραστηριοτήτων
   - **Στιγμιότυπα (Gallery)**: ανέβασμα/αλλαγή φωτογραφιών στη gallery
   - **Συχνές Ερωτήσεις**: προσθήκη/επεξεργασία FAQ
   - **Ανακοινώσεις**: νέα ανακοίνωση/νέο (σαν απλό blog — τίτλος,
     ημερομηνία, κείμενο), εμφανίζεται στη σελίδα `news.html`

   Οι φωτογραφίες (image widget) ανεβαίνουν κατευθείαν από τον υπολογιστή
   ή το κινητό — κανένα άλλο εργαλείο δεν χρειάζεται. Το "Save" κάνει
   commit στο GitHub και το Netlify αναδημοσιεύει αυτόματα σε ~30 δευτ.

> Αν προτιμάς να φιλοξενήσεις στο **Vercel** αντί για Netlify, το site
> λειτουργεί κανονικά — απλά το κομμάτι CMS/login (`admin/`) χρειάζεται
> ένα επιπλέον δωρεάν OAuth proxy, αφού το Git Gateway είναι λειτουργία
> ειδικά του Netlify. Πες μου αν θες τα βήματα για αυτό το setup.

## Δοκιμή στον υπολογιστή σου

Το site χρησιμοποιεί `fetch()` για header/footer/περιεχόμενο, οπότε
**δεν δουλεύει αν ανοίξεις απευθείας το index.html** (file://). Χρειάζεται
τοπικός server:
```
npx serve .
```

## Ανέβασμα δωρεάν

- **Netlify** (προτείνεται, για το CMS): σύρε-άφησε τον φάκελο ή σύνδεσε
  GitHub repo.
- **Vercel**: "Add New Project" → GitHub repo → Deploy (Framework: "Other").
- **GitHub Pages / Cloudflare Pages**: εναλλακτικές, εξίσου δωρεάν.

Custom domain και SSL είναι δωρεάν και στα τρία.

## Ιδέες για μελλοντικές προσθήκες
- Πραγματικό ημερολόγιο διαθεσιμότητας (π.χ. Google Calendar API) αντί για
  τη λίστα TAKEN_SLOTS στο `js/booking.js`.
- Ενσωμάτωση Google Analytics ή Meta Pixel (δωρεάν) για μέτρηση επισκεψιμότητας.
